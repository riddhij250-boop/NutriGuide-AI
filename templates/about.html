ℹ️ About NutriGuide AI

A BCA AI/ML college project for smart nutrition

🥗

What is NutriGuide AI?

NutriGuide AI is a Smart Food Recommendation System built as a BCA AI/ML college project. It uses a rule-based recommendation algorithm to suggest foods that match your dietary preferences, health goals, and available ingredients — without requiring any paid API or internet connection.

The goal is to help people make better food choices by providing personalised recommendations along with full nutritional information for each food item.

🛠️ Technology Stack

Simple, beginner-friendly technologies

🐍

Python 3

Main programming language for the backend logic and recommendation algorithm.

⚗️

Flask

Lightweight Python web framework to create the server and handle HTTP requests.

🗃️

SQLite

Simple file-based database to store all 35 food items. No server setup needed.

🌐

HTML/CSS/JS

Frontend technologies for a responsive, modern user interface with animations.

🤖 How the Recommendation Works

Simple, transparent, and understandable

The recommendation engine scores each food out of 100 points based on how well it matches your preferences:

30 pts
Diet Type Match
Food matches your dietary preference (vegan, vegetarian, etc.)
25 pts
Health Goal Match
Food is specifically good for your health goal
20 pts
Meal Type Match
Food is suitable for the meal type you selected
15 pts
Ingredients Match
Food uses ingredients you already have at home
10 pts
Cuisine Match
Food belongs to your preferred cuisine
Allergen Filter: Foods containing any of your allergens are completely removed from results, regardless of their score.

📁 Project Structure

What each file does

📁 static/js/ JavaScript files that make the pages interactive
